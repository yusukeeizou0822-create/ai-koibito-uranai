# 開発ルール

このドキュメントは、Claude Code（AIコーディングエージェント）と協働して本プロジェクトを開発する際の運用ルールをまとめたものです。

## 指示の出し方

- 指示冒頭に `git branch` → `git checkout develop`
- コード変更を伴う指示の最後は `npx tsc --noEmit` → `git add` / `git commit` / `git push origin develop`
- 調査のみの指示には「コード変更・コミット・push禁止」と明記する
- 指示は1コードブロックにまとめる

## 変更の進め方

- 構造への不安要素がある変更は先に「調査のみ」の指示を出す
- 実装中の追加判断はClaude Codeに選択肢提示させ人間が選ぶ

## キャラクター・コンテンツ設計

- キャラ性格・口調・占い文言トーン等は先にテキストで確定する

## ブランチ運用

- mainブランチには直接コミットしない
- develop→mainマージは4ステップ固定
